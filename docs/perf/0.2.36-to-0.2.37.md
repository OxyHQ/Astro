# 0.2.36 → 0.2.37 release gate

0.2.37 adds the sidebar's tab open and close motion, the hover check in the react-native-macos patch, the full-screen Space fix, Chrome's Task Manager and Battery Saver, the update channel and the security gates. Both apps are native API 9, so native-bench ran the candidate's bench bundle on both (only native code differs) and js-bench ran each app's own bundle. Measured on 2026-10-15 under the perflab lock, interleaved, display awake: `dist/0.2.37-rc/export/Astro.app` (built from e223dadf, notarized) against `dist/0.2.36/export/Astro.app`.

Three rounds. Round 1 (candidate from 7a4b5a8e) had new tab and new window first paint 5 to 11 ms slower with ranges apart over 2 runs; a second interleaved round of `--only newtab,newwindow --runs 4` overlapped (new tab first paint 124 ms (111–132) against 114 ms (113–124)), so that was noise. Round 1's close20 was a real regression from the close fade (commits 27 → 47, otherJsMs 88 → 110); e223dadf retired ghosts without a commit and the candidate was rebuilt. Round 3 below is the final candidate. The owner was using the Mac during round 3's idle windows (about 60 s per run on both sides), which spreads the launch and idle rows; every row overlaps or is better.
