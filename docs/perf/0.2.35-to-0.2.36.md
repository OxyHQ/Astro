# 0.2.35 → 0.2.36 release gate

0.2.36 runs on 0.2.35's engine (Chromium 8037@{#1673}, the same framework build): the sidebar drag
area (PR #9, native API 8 → 9), switches on the native driver, the pin target, the popovers' top gap, the History page
(PR #8) and the import fixes. Measured on 2026-10-15 from 07:25 to 08:45 IST: `dist/0.2.36/export/Astro.app` (built from
57875bbe, notarized; the shipped build) against `dist/0.2.35/export/Astro.app`, interleaved, under the perflab lock, with
nothing else of ours running and the display awake. The native API versions differ, so 0.2.35 ran its own bench bundle
(`dist/0.2.35/bench/main.jsbundle`, built from `git archive v0.2.35`); 0.2.36's is kept at `dist/0.2.36/bench/`.

Two session rounds broke off before this one and were thrown away. In the first, the 0.2.36 copy was handed links from
other apps (gist.github.com windows that the bench never opens), came to the front and was quit by hand; test builds
were unregistered from Launch Services before the rerun. In the second, native-bench read a restored tab's marks
before its page script had set them (`st.shown` undefined) and threw; it now treats that as nothing shown yet.

commits, host updates and store updates are equal.
