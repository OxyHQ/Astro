# 0.2.33 → 0.2.34 release gate

0.2.34 is drag a tab onto a tab to group them, dragging a member out of a group in the top strip, the pinned-group
drag loop fix, settings sync's missing values (e9fc5fcf, 8b4f27b2) and reopened groups' and cleaned-up tabs' history
(b2413496, 124692b1). JS only; the engine is 0.2.33's. Measured on 2026-10-12: `dist/0.2.34/export/Astro.app` (built
from 16b27f67, notarized) against `dist/0.2.33/export/Astro.app`, interleaved, under the perflab lock, with nothing else
of ours running. cpu-cap wasn't running, so nothing could pause the benches. The owner's own copy (/Applications/Astro.app)
was open throughout and idle at the end (0.0 % CPU); the owner used the Mac during some idle windows (rows below).
Both apps share native API version 8, so both ran the tree's bench bundle.

## js-bench (each app's own bundle, 3 alternating runs)

No row separates. Startup leans the other way at the medians (launch → bundle 3366 → 3574 ms, bundle → first window
158 → 183 ms) but 0.2.33's ranges (3227–4829, 144–515) cover 0.2.34's (3546–3633, 150–202), and native-bench's launch
rows, which time the same launch without the dev harness, are the same (JS running 324 → 322 ms). switch12.taskMs
189 [184–203] → 170 [169–188] and pageLoad.taskMs 99 → 87 touch or overlap.

## Verdict

Same within noise: no row separated in a second interleaved round, and nothing is measurably faster, so the notes get no
Faster section.
