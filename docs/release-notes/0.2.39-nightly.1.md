## New

- **Write your own userscripts.** The `astro` command tests a TypeScript userscript on a real page, iframes included, and installs it into Astro, the way Violentmonkey does. It works while Settings lets the astro command control Astro.
- **Daily reports from your own browsing.** `astro exec` can now read your pinned tabs and history, so an agent can sum up the sites you keep and visit.

## Fixed

- **The mini player moves when you grab it.** Dragging the Picture in Picture window failed most of the time; now it follows the pointer on every drag.
