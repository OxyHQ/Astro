## Fixed

- **AppleScript can't run code in your tabs unless you say so.** Running JavaScript in a page through AppleScript, directly or by pointing a tab at a `javascript:` address, now needs View › Developer › Allow JavaScript from Apple Events, off by default, as in Chrome.
- **Astro keeps your secure connections to itself.** Starting Astro with a key-log setting, or a saved flag that turns on network logging, no longer writes your HTTPS keys or the addresses you visit to a file.
