## Fixed

- **The Dock icon from before the rename opens Astro.** After the update to Astro, a Dock icon pinned under the old name stayed behind with the old picture and opened nothing, while Astro showed up as a second icon. On its first launch Astro points that icon at itself, or removes it when Astro is already pinned, and the Dock restarts once. Your other pinned apps stay where they were.
- **Quitting to install an update no longer crashes.** Sometimes an update ended in "Astro quit unexpectedly": as Astro closed its windows, one came back to the front and the app stopped. Closing windows are now left alone, so quitting and updating from this version on finish cleanly.
- **⇧⌘T reopens what this profile closed.** With two profiles, a tab closed in one came back after you switched to the other, and the window switched back to the first profile with it. ⇧⌘T now reopens only the tabs, windows and groups the window's current profile closed; the other profile's stay waiting in its own windows.
- **A Google search no longer shows the Maps icon while it loads.** A page Astro hadn't seen before borrowed the icon of another page on the same site, often Maps for a search. It now takes the site's own icon until the page shows its own.
- **Settings › Tabs shows the layout you're using.** It could show "Tab layout across the top of the window" selected over a window with its tabs in the sidebar, after another window or another Mac changed the layout. It now shows the front window's.

## Smaller

- Notifications from websites, and Chrome's own pages, show Astro's icon instead of Chromium's.
- With the address bar in the sidebar, the Downloads button sits level with the profile dots, clear of the window's rounded corner.
- Settings sync sends only the settings you changed on that Mac, so a Mac that never touched a setting can't undo another Mac's choice.
- A tab reopened in a pinned group keeps its Back and Forward history, even when you close it again before looking at it or close the profile's last window.
- The disk image shows Astro's icon when it's mounted.
